この道具のこと

このアプリについて

仕事をしていると、ときどき、ほんの数秒だけ手が止まる。名前は覚えている。たしか昨日も開いた。でも、そのスプレッドシートがどこにあったのか、LINE WORKSのどのトークだったのかまでは思い出せない。

検索窓を開く。履歴をたどる。チャットを少しさかのぼる。見つかってしまえば何でもない。それでも、そこへ戻るまでの小さな寄り道は、日に何度もやってくる。

Quick Project Linksは、その寄り道を少し短くするためにつくった。立派な情報管理の仕組みをつくりたいわけではない。きれいな棚を完成させることが目的でもない。いま考えていることをなるべく落とさず、そのまま次の場所へ持っていく。そのための、小さな置き場所である。

よく使うリンクは、思い出せる言葉を少し打てば出てくる。いま見ているページは、その場で置いておける。LINE WORKSなら長いURLを探さなくても、トークの番号だけでいい。何度も使う検索やプロンプトも、同じところにしまってある。

必要なものを、必要になった瞬間の近くに置いておく。

ここで大事なのは、何でも覚えさせることではないと思っている。分類は最初から完璧でなくていい。あとから名前を変えてもいいし、使わなくなったものはしまえばいい。記憶そのものを全部預けるのではなく、思い出すための手がかりだけを、手の届くところへ残しておく。それくらいが、たぶんちょうどいい。

だから、このアプリはブラウザの主役にはならない。普段は右下で小さくしていたり、サイドパネルの端にいたりする。使わない時間には、なるべく静かにしている。でも「あれ、どこだっけ」と手が止まったときには、すぐ開ける距離にいる。

リンクを開く。コピーする。検索する。一つひとつなら、ほんの数秒の作業だ。それでも仕事の流れは、案外そういう数秒で切れてしまう。小さな操作を短くするのは、時間を節約するためだけではない。さっきまで頭の中にあったものを、形を崩さずに次へ運ぶためでもある。

たぶん、ここにはこれからもリンクが増える。使わなくなるものも出てくる。分類の名前だって、いつか変わる。それでいいと思っている。完成した棚ではなく、その日の仕事に合わせて少しずつ形が変わる道具でいたい。

いつか「あのリンク、どこだっけ」と考える前に、指が先にここを開くようになったら。そのころには、探しているという感覚さえ少し薄くなっているかもしれない。

ブラウザの片隅にあるこの小さな場所が、そんなふうに、いつもの仕事の風景へ馴染んでいけばいい。

全部を覚える必要はありません。まずは「開く・探す・追加する」の3つだけで十分です。慣れてきたら、ショートカットを少しずつ使ってください。

1. まず開く

Alt + 1Linksを開く。よく使うリンクを検索・表示します。
Alt + 2REDSを開く。サイト内検索や公式X検索を使います。
Alt + 3Promptを開く。保存したプロンプトを検索・コピーします。

2. 探す・選ぶ

Alt + 4現在の検索欄へ移動。検索中なら検索語をクリアします。
Alt + FLinks検索中だけ分類候補を一覧表示。件数の多い順に並び、←→で選択、Enterで確定して絞り込んだ先頭リンクへ移動します。
Alt + QLinksの先頭を選択。↑↓でリンク移動、Enter / Spaceで開きます。
→ / ←選択したリンクから「コピー」へ移動／リンクへ戻る。
Alt + Oリンクの並び順を「新着・分類・回数」で切り替えます。

3. 追加する

Alt + NLinksでは現在のページを追加。Promptでは新規プロンプトを開きます。
✎ 手動入力URLやタイトルを自分で入力して追加します。LINE WORKSは数字・UUIDのchannelIdだけでも登録できます。
自動分類URLから分類を推測します。手動で選んだ分類は自動判定より優先されます。

4. REDS検索

Alt + S入力した語で浦和レッズ公式サイトを検索します。
Alt + X入力した語で浦和レッズ公式Xを検索します。
日付ボタン今日・昨日・1週間など、検索期間をすばやく指定できます。

5. 右下POP

Alt + W右下POPを小さくたたみます。
Alt + 5右下POPを完全に隠します。Alt + 1〜3で再び開けます。
